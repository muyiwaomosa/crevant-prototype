# Retired landing page photos

These photos were used on the earlier Splitpost homepage. The website redesign
(Master Implementation Brief, 2026-11-18) replaced them with original
illustrations. They are kept here, outside `public/`, so they stay in the
repository but are not shipped with the site.

All stock photos are licensed from Pexels (Pexels License,
https://www.pexels.com/license/), cropped, resized, converted to WebP and
stripped of metadata. They show models, never Splitpost members.
